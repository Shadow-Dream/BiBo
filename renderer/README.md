## Renderer

Render multiview RGB/D images of the scene, and place labels on the rendered image.

### Preparation

1. Install Docker on Ubuntu (we assume a headless machine).
2. Install the docker image `ghcr.io/selkies-project/nvidia-egl-desktop:latest`
3. Create a conda environment with `bpy`.
4. Install [Orient Anything](https://github.com/SpatialVision/Orient-Anything).
