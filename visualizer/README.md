## Visualizer

1. Install Unity (we use version 2022.3.17f1c1 LTS, but it should also work with other versions) on Windows via Unity Hub

2. Create a new 3D Project (Built-In Render Pipeline / Universal Render Pipeline).

3. Import the C# scripts from this folder.

4. Create an Empty Object in the scene, and attach the scripts to the Empty Object.

5. Open the Object properties and specify the Motion directory ([Download](https://huggingface.co/Behavia/BEHAVIA/tree/main/visualization/raw)) in the script properties.
