## Dataset

This folder contains the scene and task generation pipeline used to build:

- IsaacGym-importable scene assets
- Scene interaction tasks (rule-based or GPT-generated)

### Preparation

- Clone [InfiniGen](https://github.com/princeton-vl/infinigen).
- Install conda environment follow the instructions in InfiniGen.
- Put `bed.py`, `bedframe.py` and `sofa.py` under `infinigen/assets/objects/seating`.
